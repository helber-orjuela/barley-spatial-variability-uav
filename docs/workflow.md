# Reproducible Workflow

## Overview

This repository contains the analytical workflow developed for the spatial analysis of a barley experimental field integrating soil properties, crop traits, geostatistics, treatment effects, point-pattern analysis, and UAV-derived vegetation indices.

The workflow was developed to support the reproducibility of the analyses presented in the associated manuscript.

---

# Repository structure

```
code/
│
├── 01_audit_i2
├── 02_sensor_ec
├── 03_geostatistics
├── 04_treatments
├── 05_point_pattern
├── 06_soil_crop
└── 07_uav
```

Each folder contains the final R scripts used during the analysis.

---

# Analytical workflow

```
01 Data audit
        ↓
02 Electrical conductivity calibration
        ↓
03 Geostatistical analysis
        ↓
04 Treatment analysis
        ↓
05 Point-pattern analysis
        ↓
06 Soil–crop integration
        ↓
07 UAV processing
```

The output generated by each module is used as input for the subsequent analyses.

---

# Module description

## Module 01 – I2 data audit

Purpose

- verify the integrity of the input database;
- inspect coordinates, missing values and duplicated records;
- evaluate spatial consistency between sampling nodes and field boundaries.

Main outputs

- audited database;
- descriptive summaries;
- quality-control reports.

---

## Module 02 – Electrical conductivity sensor

Purpose

- compare laboratory and sensor electrical conductivity;
- fit an exploratory OLS calibration;
- evaluate prediction accuracy and residual behaviour.

Main outputs

- calibration models;
- validation statistics;
- corrected EC values.

---

## Module 03 – Geostatistics

Purpose

- characterize spatial dependence;
- fit theoretical semivariograms;
- evaluate anisotropy;
- generate ordinary kriging prediction surfaces;
- validate kriging predictions.

Main outputs

- semivariograms;
- kriging maps;
- prediction uncertainty;
- spatial validation statistics.

---

## Module 04 – Treatment analysis

Purpose

- reconstruct the experimental design;
- compare fertilizer treatments;
- evaluate crop response variables;
- assess spatial dependence of model residuals.

Main outputs

- treatment models;
- ANOVA summaries;
- residual diagnostics.

---

## Module 05 – Point-pattern analysis

Purpose

- evaluate the spatial configuration of sampling nodes;
- compare the observed pattern with complete spatial randomness;
- identify local spatial clusters.

Main outputs

- Ripley's K;
- Ripley's L;
- Kernel density;
- Local Moran's I;
- Getis–Ord Gi*.

---

## Module 06 – Soil–crop integration

Purpose

- integrate soil prediction surfaces with crop measurements;
- evaluate the contribution of soil variables to crop-response models.

Main outputs

- integrated databases;
- regression models;
- cross-validation statistics.

---

## Module 07 – UAV analysis

Purpose

- align RGB orthomosaics acquired on 9 and 14 November;
- calculate GLI and GRVI;
- compare temporal changes;
- extract vegetation-index values at crop sampling nodes.

Main outputs

- aligned orthomosaics;
- GLI maps;
- GRVI maps;
- temporal difference maps;
- extracted UAV indices.

# Software requirements

The workflow was developed using R (version 4.3 or later).

Major packages include:

- sf
- terra
- gstat
- spdep
- ggplot2
- dplyr
- tidyr
- patchwork
- writexl

Additional packages are automatically installed by individual scripts when required.

---

# Execution order

The scripts should be executed following the numerical order of the folders:

```
01_audit_i2

↓

02_sensor_ec

↓

03_geostatistics

↓

04_treatments

↓

05_point_pattern

↓

06_soil_crop

↓

07_uav
```

Executing the modules in a different order may prevent subsequent analyses from locating the required intermediate files.

---

# Reproducibility

The scripts were originally developed using local Windows paths.

Before execution, users should update the project directory defined near the beginning of each script.

Original UAV orthomosaics are not included in the repository because of their size and are intended to be archived separately through Zenodo.
