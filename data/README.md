# Data

This folder contains the data required to reproduce the analyses.

## Processed data

Small processed tables used by the R scripts will be included in this repository when redistribution is permitted.

## Large files

Original UAV orthomosaics and derived GeoTIFF files are not stored directly in GitHub because of their size. These files will be archived separately through Zenodo.

## Data notes

- Spatial data use EPSG:32618.
- Soil N, P and K are nominal instrumental indices.
- OLS-corrected EC is an exploratory linear calibration.
- Soil values extracted at crop nodes were obtained from kriging surfaces.
